# Azure Data Factory Artifacts

This directory stores JSON exports of Azure Data Factory pipelines, datasets, and linked services.

* **Pipelines**: Parameterized child ingestion pipeline and metadata-driven parent loop.
* **Datasets**: Dynamic SQL source datasets and ADLS Gen2 bronze sink datasets.
* **Linked Services**: Key Vault-backed connection definitions.

> Note: Artifacts will be populated in Stages 4, 5, and 10 upon configuring ADF Git Integration.
